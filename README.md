# SODFA Cinematic Showcase

SODFA — Premium Electronics Store Frontend

Build a premium, modern, minimalist, cinematic e-commerce frontend prototype for SODFA (صدفة), an Egyptian mobile accessories brand.

IMPORTANT

This is ONLY a frontend UI/UX prototype.

Use mock data.

Do NOT build backend, database, authentication, payment processing, customer accounts, warehouse management, real orders, Supabase integration, admin dashboard, SEO system, or advanced APIs.

Focus the available credits on creating a beautiful, polished, responsive frontend foundation that can be connected to Supabase later.
